# Write a usability test script with neutral tasks, probes, and success criteria

## Purpose

Write a usability test script with neutral tasks, probes, and success criteria.

## When to use

Use when the user needs a consistent script for evaluating a prototype or product flow.

## When NOT to use

Do not use this for the visual asset itself; use image-visual instead.

## Inputs required

- The user problem and the success criteria
- The platform and the accessibility target
- The existing design system

## Procedure

1. Define the participant profile, test scope, and session length.
2. Write task scenarios without revealing interface paths or expected actions.
3. Add neutral probes for confusion, hesitation, and unexpected behavior.
4. Define the observable success condition for each task.
5. Specify consent, recording, and data-redaction procedures.

## Output contract

A design specification with flows, states, tokens and the accessibility notes attached.

## Validation checklist

- [ ] Every state is specified, including empty and error
- [ ] Contrast and focus order are defined
- [ ] The design reuses existing tokens

## Safety notes

Never collect personal data in a flow without a stated purpose and consent point.
