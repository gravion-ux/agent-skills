# Create a visual hierarchy that makes the primary action and content order unmistakable

## Purpose

Create a visual hierarchy that makes the primary action and content order unmistakable.

## When to use

Use when the user needs to clarify emphasis and reading order on a screen.

## When NOT to use

Do not use this for the visual asset itself; use image-visual instead.

## Inputs required

- The user problem and the success criteria
- The platform and the accessibility target
- The existing design system

## Procedure

1. Rank content and actions by user importance and task priority.
2. Assign spacing, scale, weight, and contrast to express that ranking.
3. Reduce competing emphasis until the primary action stands out.
4. Verify the intended order with a five-second glance test.
5. Check that hierarchy remains clear in empty, error, and dense states.

## Output contract

A design specification with flows, states, tokens and the accessibility notes attached.

## Validation checklist

- [ ] Every state is specified, including empty and error
- [ ] Contrast and focus order are defined
- [ ] The design reuses existing tokens

## Safety notes

Never collect personal data in a flow without a stated purpose and consent point.
