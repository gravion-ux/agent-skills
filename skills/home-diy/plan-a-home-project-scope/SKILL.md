# Scope a home project with the tasks, materials, timings and finish defined before starting

## Purpose

Scope a home project with the tasks, materials, timings and finish defined before starting.

## When to use

Use when the user wants to plan a home improvement job before buying tools or materials.

## When NOT to use

Do not use this for professional structural or electrical work; use a licensed tradesperson instead.

## Inputs required

- The fixture, room and the symptom
- The tools available and the materials on hand
- Whether the work is inside or outside the warranty

## Procedure

1. Write the outcome the project must produce and the finish expected at the end.
2. List every task between the current state and that outcome.
3. Check which tasks need a trade, a permit or a power tool the user does not have.
4. Buy the materials in one list with the quantities, including ten percent extra.
5. Sequence the tasks so that nothing has to be undone later to reach it.

## Output contract

A step-by-step plan with the tools, materials, timings and the finish to expect.

## Validation checklist

- [ ] The shut-off and safety steps come first
- [ ] Materials match the existing system
- [ ] The user is told when to stop and call a professional

## Safety notes

Never advise on live electrical or gas work without a qualified professional, and always state how to shut the water or power off.
