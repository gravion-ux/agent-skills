# Choose the right tools for a job without buying tools that duplicate what is already owned

## Purpose

Choose the right tools for a job without buying tools that duplicate what is already owned.

## When to use

Use when the user needs tools for a project and wants to know what is worth buying or borrowing.

## When NOT to use

Do not use this for professional structural or electrical work; use a licensed tradesperson instead.

## Inputs required

- The fixture, room and the symptom
- The tools available and the materials on hand
- Whether the work is inside or outside the warranty

## Procedure

1. Write the tasks the tools must cover, not the tools themselves.
2. List the tools already available and mark them as owned, borrowed or hireable.
3. For each remaining task, decide between buying, borrowing and hiring.
4. Check that any purchased tool fits the space and the user's actual strength.
5. Buy the tool that covers the most tasks first, and rent the specialist ones.

## Output contract

A step-by-step plan with the tools, materials, timings and the finish to expect.

## Validation checklist

- [ ] The shut-off and safety steps come first
- [ ] Materials match the existing system
- [ ] The user is told when to stop and call a professional

## Safety notes

Never advise on live electrical or gas work without a qualified professional, and always state how to shut the water or power off.
