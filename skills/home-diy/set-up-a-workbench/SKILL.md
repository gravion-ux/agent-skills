# Set up a workbench that is stable, at the right height and strong enough for the work

## Purpose

Set up a workbench that is stable, at the right height and strong enough for the work.

## When to use

Use when the user wants a dedicated bench for home projects.

## When NOT to use

Do not use this for professional structural or electrical work; use a licensed tradesperson instead.

## Inputs required

- The fixture, room and the symptom
- The tools available and the materials on hand
- Whether the work is inside or outside the warranty

## Procedure

1. Measure the space and choose a bench that leaves room to work from both sides.
2. Set the bench height so the forearms rest on it without raising the shoulders.
3. Check the top is flat and does not wobble, then fix it to the frame.
4. Add a shelf below for the heavy tools and a vice at the edge of the top.
5. Add lighting that lights the work rather than the user's face.

## Output contract

A step-by-step plan with the tools, materials, timings and the finish to expect.

## Validation checklist

- [ ] The shut-off and safety steps come first
- [ ] Materials match the existing system
- [ ] The user is told when to stop and call a professional

## Safety notes

Never advise on live electrical or gas work without a qualified professional, and always state how to shut the water or power off.
