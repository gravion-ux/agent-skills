# Build a moodboard that aligns references, palette, typography, and texture to a visual direction

## Purpose

Build a moodboard that aligns references, palette, typography, and texture to a visual direction.

## When to use

Use when the user needs to collect visual references and define a shared creative direction.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. Collect a focused set of licensed references with source and usage notes.
2. Sort references into composition, color, type, texture, and lighting groups.
3. Define a three-to-five color palette and type hierarchy from the selected references.
4. Arrange the board so the dominant direction is visible before supporting details.
5. Record the approved direction and the rules for future assets.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
