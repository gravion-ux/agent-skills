# Write a visual brief that gives a designer a clear deliverable, constraints, and acceptance criteria

## Purpose

Write a visual brief that gives a designer a clear deliverable, constraints, and acceptance criteria.

## When to use

Use when the user needs to hand a still-visual project to another designer or studio.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. State the business goal, audience, intended use, and single primary message.
2. Define required assets, dimensions, content hierarchy, and delivery formats.
3. Specify style references, palette, typography, logo, and accessibility constraints.
4. Document rights, consent, and licensing limits for supplied materials.
5. List acceptance checks, deadlines, owners, and the approval decision process.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
