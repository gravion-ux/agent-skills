# Create a flat illustration with clear shapes, restrained color, and consistent spacing

## Purpose

Create a flat illustration with clear shapes, restrained color, and consistent spacing.

## When to use

Use when the user wants a simple vector-style illustration for digital or print use.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. Define the focal subject, canvas ratio, and maximum number of colors.
2. Describe geometry, overlap, and negative space using simple directional language.
3. Choose one flat rendering treatment and keep gradients, shadows, and texture out.
4. Export at the requested dimensions and inspect edges for unintended gaps.
5. Check that the illustration remains recognizable at thumbnail size.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
