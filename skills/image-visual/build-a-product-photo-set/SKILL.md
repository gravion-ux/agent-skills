# Create a coordinated product photo set with consistent framing, lighting, and background treatment

## Purpose

Create a coordinated product photo set with consistent framing, lighting, and background treatment.

## When to use

Use when the user needs several still views of one product for a listing or campaign.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. List every required angle, scale, detail crop, and final file size.
2. Define fixed camera height, distance, lighting, and background rules for the set.
3. Capture or generate each view against the same setup.
4. Check consistency of scale, color, shadows, and whitespace across the set.
5. Export with stable filenames and record the shared production settings.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
