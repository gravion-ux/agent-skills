# Build a visual style guide that turns approved references into repeatable asset rules

## Purpose

Build a visual style guide that turns approved references into repeatable asset rules.

## When to use

Use when the user needs an enforceable visual standard for a brand or creative team.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. Collect approved brand assets, references, and existing asset samples.
2. Define color roles, typography, spacing, imagery, logo, and layout rules.
3. Specify permitted treatments, prohibited uses, and accessibility requirements.
4. Add examples for each rule with labels that state the intended application.
5. Assign an owner and review cycle for approving future exceptions.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
