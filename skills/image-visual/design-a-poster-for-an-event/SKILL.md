# Design an event poster with readable hierarchy, accurate details, and print-ready dimensions

## Purpose

Design an event poster with readable hierarchy, accurate details, and print-ready dimensions.

## When to use

Use when the user needs a static poster for an event, announcement, or campaign.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. Collect the event name, date, time, venue, organizer, and final poster size.
2. Choose a focal visual and hierarchy that keeps the event name dominant.
3. Place logistics details in legible type with sufficient contrast and spacing.
4. Verify dates, times, locations, logos, and sponsor marks against supplied assets.
5. Export with crop and bleed settings appropriate for the chosen printer.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
