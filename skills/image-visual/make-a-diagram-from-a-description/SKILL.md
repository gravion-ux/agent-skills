# Convert a written system description into a labelled diagram with unambiguous relationships

## Purpose

Convert a written system description into a labelled diagram with unambiguous relationships.

## When to use

Use when the user has a process or architecture description that must become a static diagram.

## When NOT to use

Do not use this for a motion asset; use video-audio instead.

## Inputs required

- The subject and the intended use
- The style, aspect ratio and resolution
- The licensing and brand constraints

## Procedure

1. Extract the actors, components, states, and relationships from the description.
2. Choose a diagram structure that matches the flow or hierarchy.
3. Label each element and connection using consistent nouns and arrow directions.
4. Place related elements together and remove any relationship the text does not support.
5. Review the diagram against every statement in the source description.

## Output contract

A finished visual asset at the requested size, with its prompt or edit history recorded.

## Validation checklist

- [ ] The asset matches the required dimensions
- [ ] No unlicensed or trademarked material is present
- [ ] Text in the image is legible

## Safety notes

Never create or edit an image of a real person without consent, and never reuse licensed material.
