# Set a boundary that is specific, said once and does not invite negotiation

## Purpose

Set a boundary that is specific, said once and does not invite negotiation.

## When to use

Use when the user needs to say no, or to limit what they are willing to keep doing.

## When NOT to use

Do not use this for a workplace conflict that needs a formal process; use communication or business-ops instead.

## Inputs required

- The situation and the relationship
- What the user wants to happen next
- The tone and the boundaries that apply

## Procedure

1. Write the boundary as one plain sentence with a concrete limit in it.
2. State it without justifying it at length, because justification invites debate.
3. Name what the user is willing to do instead, if anything.
4. Plan the exact moment and channel for saying it.
5. Decide in advance the repeated response if the boundary is tested again.

## Output contract

A suggested approach with wording the user can adapt, plus the outcome to watch for.

## Validation checklist

- [ ] The tone matches the relationship
- [ ] The ask is reasonable and specific
- [ ] The user can edit before sending

## Safety notes

Never send the message without approval, and never advise on a situation where the user is at risk of harm.
