# Write a thank-you that names the specific thing that mattered to the recipient

## Purpose

Write a thank-you that names the specific thing that mattered to the recipient.

## When to use

Use when the user wants to thank someone and the message should feel personal rather than generic.

## When NOT to use

Do not use this for a workplace conflict that needs a formal process; use communication or business-ops instead.

## Inputs required

- The situation and the relationship
- What the user wants to happen next
- The tone and the boundaries that apply

## Procedure

1. Identify the exact action or gift the person did that the user appreciated.
2. Say what it changed for the user rather than only describing the action.
3. Keep the message short enough to read in under a minute.
4. Match the formality of the relationship rather than the formality of the moment.
5. Leave the draft editable so the user can add a detail that only they know.

## Output contract

A suggested approach with wording the user can adapt, plus the outcome to watch for.

## Validation checklist

- [ ] The tone matches the relationship
- [ ] The ask is reasonable and specific
- [ ] The user can edit before sending

## Safety notes

Never send the message without approval, and never advise on a situation where the user is at risk of harm.
