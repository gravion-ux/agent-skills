# Talk to a parent about something difficult by giving them context and a clear ask

## Purpose

Talk to a parent about something difficult by giving them context and a clear ask.

## When to use

Use when the user needs to raise a sensitive topic with a parent or older relative.

## When NOT to use

Do not use this for a workplace conflict that needs a formal process; use communication or business-ops instead.

## Inputs required

- The situation and the relationship
- What the user wants to happen next
- The tone and the boundaries that apply

## Procedure

1. Decide how much detail the parent needs and what they can actually act on.
2. Choose a moment when they are rested and not in the middle of something else.
3. Start with what the parent has already noticed, so the news does not arrive cold.
4. Make one specific request and be ready for the answer to be no.
5. Agree what happens next if they need time to think about it.

## Output contract

A suggested approach with wording the user can adapt, plus the outcome to watch for.

## Validation checklist

- [ ] The tone matches the relationship
- [ ] The ask is reasonable and specific
- [ ] The user can edit before sending

## Safety notes

Never send the message without approval, and never advise on a situation where the user is at risk of harm.
