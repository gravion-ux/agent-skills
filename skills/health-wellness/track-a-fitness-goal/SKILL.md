# Track a fitness goal with one honest measure and a weekly review that changes the plan

## Purpose

Track a fitness goal with one honest measure and a weekly review that changes the plan.

## When to use

Use when the user wants to track progress towards a fitness goal over weeks or months.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Choose a single measure that reflects the goal, such as a load, a time or a count.
2. Record the starting value and the date it was taken.
3. Log the measure on a fixed schedule that matches the training rhythm.
4. Review the trend weekly rather than reading a single session.
5. Adjust the plan only when the trend has been flat for two weeks.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
