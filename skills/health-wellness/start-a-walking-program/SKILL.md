# Start a walking program that builds distance gradually and stays easy to continue

## Purpose

Start a walking program that builds distance gradually and stays easy to continue.

## When to use

Use when the user wants to begin walking regularly as exercise.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Check whether a clinician should be consulted before starting, if there is a relevant condition.
2. Set the first week's duration from the user's current baseline rather than a target.
3. Add a small number of minutes each week, not each day.
4. Plan a route and a pair of shoes that make the walk pleasant.
5. Record each walk so the streak is visible and the habit is easy to keep.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
