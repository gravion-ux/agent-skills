# Set a fitness milestone that is measurable, gradual and achievable within the stated time

## Purpose

Set a fitness milestone that is measurable, gradual and achievable within the stated time.

## When to use

Use when the user wants a fitness target that will not be unrealistic or vague.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Write the target as a number on a measure, not as a feeling.
2. Compare the target with the user's current baseline and the time available.
3. Split the gap into equal steps across the weeks available.
4. Add the conditions that would make the milestone need to move, such as illness.
5. Set a review point where the target is checked and can be adjusted without shame.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
