# Prepare for a medical appointment so the time is used on the questions that matter

## Purpose

Prepare for a medical appointment so the time is used on the questions that matter.

## When to use

Use when the user wants to get ready for an appointment with a clinician.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Write the main concern in one sentence and rank the other symptoms below it.
2. List when each symptom started, how often it happens and what makes it worse.
3. Bring the medication list, the doses and the dates of any test results.
4. Write down three questions and leave room to write the answers down.
5. Ask what to watch for and when to come back, before leaving the appointment.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
