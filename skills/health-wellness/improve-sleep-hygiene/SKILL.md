# Improve sleep hygiene by fixing the specific habits that disrupt sleep

## Purpose

Improve sleep hygiene by fixing the specific habits that disrupt sleep.

## When to use

Use when the user wants practical changes that will improve the quality of their sleep.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. List the three habits that most often disrupt sleep for the user.
2. Fix the environment first, covering light, noise and temperature.
3. Stop caffeine well before the target bedtime based on how it affects the user.
4. Keep the bed for sleep only and leave it if the user cannot sleep.
5. Change one habit per week so the effect of each change is visible.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
