# Build an exercise routine that fits the user's real week and can be kept going

## Purpose

Build an exercise routine that fits the user's real week and can be kept going.

## When to use

Use when the user wants a regular exercise habit that will not collapse after a week.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Confirm the current baseline, the days available and the equipment on hand.
2. Choose the number of sessions that fits the week before the days are named.
3. Start each session below the user's current capacity so the first week succeeds.
4. Add one small increase only after two consecutive comfortable weeks.
5. Write the minimum version of the session that still counts on a bad day.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
