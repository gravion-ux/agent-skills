# Build a stress-relief routine with a short daily practice and a heavier-day fallback

## Purpose

Build a stress-relief routine with a short daily practice and a heavier-day fallback.

## When to use

Use when the user wants a repeatable way to manage everyday stress.

## When NOT to use

Do not use this for a medical diagnosis or an acute emergency; use a qualified clinician instead.

## Inputs required

- The goal and the current baseline
- The time, equipment and mobility available
- Any constraints the user has stated

## Procedure

1. Identify the physical signs of stress that show up first for the user.
2. Choose one short daily practice that can be done anywhere.
3. Pair it with a longer weekly practice for the days that need more.
4. Remove one recurring source of stress from the schedule rather than only coping with it.
5. Review after a fortnight and keep only the practices that actually helped.

## Output contract

A realistic plan with weekly structure, a simple tracking method and clear stopping conditions.

## Validation checklist

- [ ] The plan matches the stated baseline and constraints
- [ ] Progression is gradual and reversible
- [ ] The plan says when to seek professional advice

## Safety notes

Never diagnose, prescribe or set medical targets, and never encourage a routine that contradicts a clinician's advice.
