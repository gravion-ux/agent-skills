# Give writing feedback that names what to change and shows how, rather than only judging it

## Purpose

Give writing feedback that names what to change and shows how, rather than only judging it.

## When to use

Use when the user wants to return feedback on a piece of writing.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Quote the exact sentence that caused the strongest reaction for the reader.
2. Explain the effect it had on the reader, not the rule that was broken.
3. Suggest one specific change with an example of the revised wording.
4. Name the two things that work well, so the learner knows what to keep.
5. Set one instruction for the next draft rather than a list of many.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
