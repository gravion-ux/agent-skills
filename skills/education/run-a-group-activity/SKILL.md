# Run a group activity where every member has a role and the output is collected on time

## Purpose

Run a group activity where every member has a role and the output is collected on time.

## When to use

Use when the user is leading a group task in a class or a workshop.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Give each role a specific job, such as facilitator, recorder or timekeeper.
2. State the deliverable and the time limit before the groups start.
3. Set the group size so the work is still possible in the time available.
4. Check in at the halfway point and ask what is stuck.
5. Collect the output from each group and state what will happen with it.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
