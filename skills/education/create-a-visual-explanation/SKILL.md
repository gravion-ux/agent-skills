# Create a visual explanation that shows the relationship rather than decorating the text

## Purpose

Create a visual explanation that shows the relationship rather than decorating the text.

## When to use

Use when the user wants a diagram, chart or image to make a concept clearer.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Write what the viewer must understand after looking at it.
2. Choose the form that matches the relationship, such as a flow, a comparison or a sequence.
3. Reduce the content to the smallest set of elements that still shows the relationship.
4. Label everything directly, because a legend makes people decode before they understand.
5. Check the visual works at the size it will actually be seen.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
