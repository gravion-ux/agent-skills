# Create a project-based unit with a driving question, a deliverable and a clear assessment

## Purpose

Create a project-based unit with a driving question, a deliverable and a clear assessment.

## When to use

Use when the user wants to teach a topic through an extended project.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Write the driving question that the project will actually answer.
2. Define the deliverable and the criteria that will be judged.
3. List the knowledge and skills the project requires and check the class has them.
4. Break the project into milestones with feedback points between them.
5. Set the groups, the roles and the final presentation or sharing.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
