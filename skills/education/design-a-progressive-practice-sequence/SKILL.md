# Design a practice sequence that moves from supported to independent in small steps

## Purpose

Design a practice sequence that moves from supported to independent in small steps.

## When to use

Use when the user wants an ordered set of practice tasks that builds a skill.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Start with a task where the steps are given and the learners only execute them.
2. Move to a task where one step must be chosen by the learner.
3. Move to a task where the learners must plan the whole procedure.
4. Keep the context stable at first, then vary it in the final tasks.
5. Add a mixed set of earlier items as the final assessment.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
