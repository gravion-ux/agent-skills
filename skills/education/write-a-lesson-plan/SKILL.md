# Write a lesson plan with the objective, the activity timings and the materials listed

## Purpose

Write a lesson plan with the objective, the activity timings and the materials listed.

## When to use

Use when the user needs to prepare a single session for a class or a group.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Write the one objective the session is judged on.
2. Break the session into a starter, the main activity and the closing check.
3. Give each part a timing that adds up to the length of the session.
4. List the materials and prepare them before the session starts.
5. Write the question the closing check will ask, and the answer to look for.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
