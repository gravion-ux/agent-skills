# Differentiate a task for mixed ability by keeping the outcome shared and the support different

## Purpose

Differentiate a task for mixed ability by keeping the outcome shared and the support different.

## When to use

Use when the user is teaching one task to a group with different levels.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Define the outcome that every learner works towards.
2. Prepare a scaffolded version with the intermediate step shown.
3. Prepare an extension that adds a constraint or a second case.
4. Make the task text identical apart from the support, so it stays fair.
5. Plan how learners move between the versions without it being obvious.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
