# Plan a course syllabus that maps each week to an objective and an assessed outcome

## Purpose

Plan a course syllabus that maps each week to an objective and an assessed outcome.

## When to use

Use when the user is designing the outline for a course or a teaching block.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Write the learning objectives as what a learner will be able to do, not what they will know.
2. List the topics in the order that builds on itself, and check nothing depends on later material.
3. Give each session an objective, an activity and the piece of work that shows it was met.
4. State how the work is assessed and when the feedback is returned.
5. Add the reading and the preparation the learner needs before each session.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
