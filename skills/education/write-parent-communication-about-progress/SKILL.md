# Write a parent message about a learner's progress that is specific, factual and actionable

## Purpose

Write a parent message about a learner's progress that is specific, factual and actionable.

## When to use

Use when the user needs to inform a parent or guardian about how a learner is doing.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. State the specific progress, with the work it refers to.
2. Name the area the learner is strongest in, with the same specificity.
3. Describe the one thing that needs attention, without labelling the learner.
4. Say what the learner is doing about it and what the school is doing.
5. Ask for one specific action at home and suggest how to contact if there are questions.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
