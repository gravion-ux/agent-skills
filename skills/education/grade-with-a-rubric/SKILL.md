# Grade with a rubric by stating the criteria and the levels before the work is read

## Purpose

Grade with a rubric by stating the criteria and the levels before the work is read.

## When to use

Use when the user wants to grade work consistently against stated criteria.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. List the criteria and the performance levels for each one.
2. Write the descriptor for each level in terms of what the work actually shows.
3. State how the levels combine into the final mark.
4. Apply the rubric to one sample before grading the rest.
5. Give each learner the rubric with the feedback so the mark is not a mystery.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
