# Build a knowledge check that tests recall quickly and points to what to review

## Purpose

Build a knowledge check that tests recall quickly and points to what to review.

## When to use

Use when the user wants a short quiz to check what has been retained.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Pick the facts that matter for the next task, not everything covered.
2. Write short questions with one unambiguous answer each.
3. Include one or two distractors that come from a real misconception.
4. Mark the answer and the source page for every question.
5. Write the review step for anyone who scores below the pass mark.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
