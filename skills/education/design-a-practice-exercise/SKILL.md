# Design a practice exercise that isolates one skill and gives feedback on it

## Purpose

Design a practice exercise that isolates one skill and gives feedback on it.

## When to use

Use when the user wants an exercise for learners to practise a specific thing.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Name the single skill the exercise practises.
2. Choose the task type that matches where the learners currently are.
3. Make the task require the skill rather than recall of a fact.
4. Include one item that would expose a common mistake.
5. Write the feedback for each outcome so the learner knows what to do next.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
