# Explain a concept three times, at a simple level, a working level and a precise level

## Purpose

Explain a concept three times, at a simple level, a working level and a precise level.

## When to use

Use when the user wants an explanation of one idea that works for different audiences.

## When NOT to use

Do not use this for self-directed study; use learning-skills instead.

## Inputs required

- The learner group and their level
- The learning objectives
- The session format and the time available

## Procedure

1. Write the plain version with no jargon and one concrete example.
2. Write the working version with the terms a practitioner would use.
3. Write the precise version with the formal definition and its boundary conditions.
4. Check that all three versions describe the same idea and do not contradict each other.
5. Label each version so the reader knows which one they are looking at.

## Output contract

A lesson plan with objectives, activities, materials and an assessment.

## Validation checklist

- [ ] Every objective has an activity and an assessment
- [ ] The difficulty matches the learner level
- [ ] Materials are ready before the session

## Safety notes

Never use copyrighted source material without permission, and never grade a person without stating the rubric.
