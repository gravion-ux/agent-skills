# Write a recommendation that makes the colleague's case with evidence rather than adjectives

## Purpose

Write a recommendation that makes the colleague's case with evidence rather than adjectives.

## When to use

Use when the user has been asked to recommend someone for a role, a course or an award.

## When NOT to use

Do not use this for formal published documentation; use technical-writing instead.

## Inputs required

- The audience and their prior knowledge
- The message and the outcome wanted
- The channel and the deadline

## Procedure

1. State what the person is being recommended for in the first line.
2. Give two or three concrete examples of the work that shows the capability.
3. Describe the context of each example, so the reader can judge its scale.
4. Compare the person against the requirement for the role, not against other people.
5. State the reservation honestly if there is one, because a review will find it anyway.

## Output contract

A message ready to send, with the ask, the context and the next step made explicit.

## Validation checklist

- [ ] The ask is stated in one sentence
- [ ] The tone matches the audience and channel
- [ ] The next step and its owner are clear

## Safety notes

Never send a message on the user's behalf without explicit approval of the final text.
