# Build a structured interview plan where each question probes a stated criterion

## Purpose

Build a structured interview plan where each question probes a stated criterion.

## When to use

Use when the user wants to design the interviews for a hiring stage.

## When NOT to use

Do not use this for an onboarding checklist for an existing employee; use business-ops instead.

## Inputs required

- The role, the team and the hiring stage
- The candidate material in scope
- The evaluation criteria and the decision timeline

## Procedure

1. List the criteria that still need evidence at this stage.
2. Write the question for each criterion and the signal that would answer it.
3. Add the follow-up questions that go deeper if the answer is thin.
4. Write the scoring anchors for a strong, an adequate and a weak answer.
5. Check that every criterion is covered and that no question repeats another.

## Output contract

A structured evaluation or hiring artefact that applies the stated criteria consistently.

## Validation checklist

- [ ] Every criterion is applied to every candidate
- [ ] The decision is traceable to the criteria
- [ ] Personal data is limited to what the process needs

## Safety notes

Never make a hiring decision without human review, and never infer protected attributes from a CV.
