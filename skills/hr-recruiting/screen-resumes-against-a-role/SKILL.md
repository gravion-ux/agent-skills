# Screen resumes against a role using the same criteria for every candidate

## Purpose

Screen resumes against a role using the same criteria for every candidate.

## When to use

Use when the user needs to reduce a pile of applications to a shortlist.

## When NOT to use

Do not use this for an onboarding checklist for an existing employee; use business-ops instead.

## Inputs required

- The role, the team and the hiring stage
- The candidate material in scope
- The evaluation criteria and the decision timeline

## Procedure

1. Write the criteria from the job description before opening any resume.
2. Note the evidence for each criterion for every applicant, including the gaps.
3. Compare the applicants against the criteria only, not against each other.
4. Keep the shortlist at a fixed size agreed before the review started.
5. Record the reason for each decision so it can be explained later.

## Output contract

A structured evaluation or hiring artefact that applies the stated criteria consistently.

## Validation checklist

- [ ] Every criterion is applied to every candidate
- [ ] The decision is traceable to the criteria
- [ ] Personal data is limited to what the process needs

## Safety notes

Never make a hiring decision without human review, and never infer protected attributes from a CV.
