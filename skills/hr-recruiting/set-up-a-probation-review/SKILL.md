# Set up a probation review that measures the role against expectations set at the start

## Purpose

Set up a probation review that measures the role against expectations set at the start.

## When to use

Use when the user needs to plan an end-of-probation conversation.

## When NOT to use

Do not use this for an onboarding checklist for an existing employee; use business-ops instead.

## Inputs required

- The role, the team and the hiring stage
- The candidate material in scope
- The evaluation criteria and the decision timeline

## Procedure

1. List the expectations that were agreed at the start, in writing, with the dates.
2. Gather the evidence for each expectation from the probation period.
3. Ask the person to self-assess before the review conversation.
4. Compare the evidence against each expectation and write the gaps specifically.
5. Agree either confirmation, extension with clear targets, or an ending, and record it.

## Output contract

A structured evaluation or hiring artefact that applies the stated criteria consistently.

## Validation checklist

- [ ] Every criterion is applied to every candidate
- [ ] The decision is traceable to the criteria
- [ ] Personal data is limited to what the process needs

## Safety notes

Never make a hiring decision without human review, and never infer protected attributes from a CV.
