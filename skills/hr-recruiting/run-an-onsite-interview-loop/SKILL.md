# Run an onsite interview loop where each interviewer scores independently before the debrief

## Purpose

Run an onsite interview loop where each interviewer scores independently before the debrief.

## When to use

Use when the user is organising a full onsite day for a candidate.

## When NOT to use

Do not use this for an onboarding checklist for an existing employee; use business-ops instead.

## Inputs required

- The role, the team and the hiring stage
- The candidate material in scope
- The evaluation criteria and the decision timeline

## Procedure

1. Assign each interviewer a distinct set of criteria so the same ground is not covered twice.
2. Set the schedule with breaks and with the interviewers given the brief in advance.
3. Collect each written score before any discussion of the candidate begins.
4. Run the debrief with the scores visible and resolve disagreements against the criteria.
5. Record the decision and the evidence for each criterion.

## Output contract

A structured evaluation or hiring artefact that applies the stated criteria consistently.

## Validation checklist

- [ ] Every criterion is applied to every candidate
- [ ] The decision is traceable to the criteria
- [ ] Personal data is limited to what the process needs

## Safety notes

Never make a hiring decision without human review, and never infer protected attributes from a CV.
