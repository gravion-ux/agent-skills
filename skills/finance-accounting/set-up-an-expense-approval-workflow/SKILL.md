# Set up an expense approval workflow with clear thresholds, evidence rules and a record

## Purpose

Set up an expense approval workflow with clear thresholds, evidence rules and a record.

## When to use

Use when the user wants a consistent process for approving expenses.

## When NOT to use

Do not use this for a budget spreadsheet for a small team; use personal-finance instead.

## Inputs required

- The transactions, invoices or ledger in scope
- The accounting rules and the reporting period
- The reconciliation tolerance

## Procedure

1. Set the thresholds by amount and by the type of expense.
2. Name the approver for each threshold and a second approver above the highest one.
3. Define the evidence required at each level, such as a receipt or a written reason.
4. Set the deadline for the approver to respond and what happens when it is missed.
5. Keep one record of every request and decision so the same claim cannot be submitted twice.

## Output contract

A reconciled ledger or report with every difference explained and flagged.

## Validation checklist

- [ ] The totals tie to the source records
- [ ] Every adjustment is traceable to a rule or an approval
- [ ] Rounding differences are within tolerance

## Safety notes

Never post, approve or pay a transaction without explicit authorisation, and never alter a closed period.
