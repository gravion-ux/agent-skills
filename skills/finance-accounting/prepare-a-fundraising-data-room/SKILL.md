# Prepare a fundraising data room with an index, clean figures and the source records behind them

## Purpose

Prepare a fundraising data room with an index, clean figures and the source records behind them.

## When to use

Use when the user is preparing documents for investors, lenders or due diligence.

## When NOT to use

Do not use this for a budget spreadsheet for a small team; use personal-finance instead.

## Inputs required

- The transactions, invoices or ledger in scope
- The accounting rules and the reporting period
- The reconciliation tolerance

## Procedure

1. List the document categories the reviewer expects and build an index against them.
2. Reconcile every figure in the financial model to the source records.
3. Remove drafts, duplicates and any document containing personal or confidential data that is not needed.
4. Name the version and the date for each file so the reviewer knows what is current.
5. Record who has access and log every file that is added after the first opening.

## Output contract

A reconciled ledger or report with every difference explained and flagged.

## Validation checklist

- [ ] The totals tie to the source records
- [ ] Every adjustment is traceable to a rule or an approval
- [ ] Rounding differences are within tolerance

## Safety notes

Never post, approve or pay a transaction without explicit authorisation, and never alter a closed period.
