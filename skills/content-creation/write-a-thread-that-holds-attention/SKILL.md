# Sequence a social thread so each post pulls the reader into the next one

## Purpose

Sequence a social thread so each post pulls the reader into the next one.

## When to use

Use when the user wants a multi-post thread that keeps readers scrolling.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Lead with the most surprising or useful claim in the first post.
2. Split the argument into posts that each make one point.
3. End each post with a question or reason to read the next.
4. Vary post length so the rhythm breaks before the thread ends.
5. Close the final post with the summary and a call to action.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
