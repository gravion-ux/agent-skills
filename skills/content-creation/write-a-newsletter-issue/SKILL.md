# Write a newsletter issue with a subject line, sections and a single primary action

## Purpose

Write a newsletter issue with a subject line, sections and a single primary action.

## When to use

Use when the user wants an email issue for subscribers.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Choose one topic that justifies the issue and name its benefit.
2. Write a subject line under fifty characters and a preview line that adds context.
3. Open with a two-sentence introduction that earns the first section.
4. Organise the body into labelled sections with one link or action each.
5. Close with one primary call to action and leave the draft unpublished.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
