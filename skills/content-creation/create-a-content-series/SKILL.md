# Plan a content series with a shared theme, episode order and release rhythm

## Purpose

Plan a content series with a shared theme, episode order and release rhythm.

## When to use

Use when the user wants a repeatable multi-part content series.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Define the single theme and the question each episode answers.
2. Write a working title and hook for every episode in the series.
3. Order the episodes so each one stands alone and builds on the last.
4. Set a release cadence and a promotion slot for each episode.
5. Write a reusable template for the format so episodes stay consistent.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
