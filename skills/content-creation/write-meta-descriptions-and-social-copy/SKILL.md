# Write meta descriptions and social copy that match the page's hook and audience

## Purpose

Write meta descriptions and social copy that match the page's hook and audience.

## When to use

Use when the user needs search and social copy for a published piece.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Summarise the piece's promise in one sentence a stranger would understand.
2. Write a meta description within the search snippet limit with the keyword early.
3. Draft two social captions that open with the hook rather than the title.
4. Include one hashtag only where it reaches the intended reader.
5. Deliver the copy attached to the page as a reviewable block.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
