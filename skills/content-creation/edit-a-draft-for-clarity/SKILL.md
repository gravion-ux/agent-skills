# Edit a draft so each sentence states one idea in plain, concrete language

## Purpose

Edit a draft so each sentence states one idea in plain, concrete language.

## When to use

Use when the user wants an existing draft tightened for clarity.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Read the draft once for the argument before editing individual sentences.
2. Cut hedging, filler and any sentence that repeats an earlier point.
3. Replace vague nouns with the specific object, number or action meant.
4. Split sentences longer than thirty words and keep one idea per sentence.
5. Read the edited draft aloud and mark every place the meaning shifts.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
