# Write a blog how-to that walks the reader from setup to a finished result

## Purpose

Write a blog how-to that walks the reader from setup to a finished result.

## When to use

Use when the user wants a step-by-step guide published as a blog post.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Name the exact result the reader will achieve by the end.
2. List the tools, access and prerequisites before the first step.
3. Write numbered steps in execution order with one action each.
4. Add a screenshot or command beside steps that depend on screen detail.
5. Close with a verification step, a troubleshooting note and a next action.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
