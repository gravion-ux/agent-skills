# Refresh an older article so its facts, examples and links are current

## Purpose

Refresh an older article so its facts, examples and links are current.

## When to use

Use when the user wants to bring a dated post back up to date.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. List every dated claim, statistic, price, link and tool reference.
2. Check each item against a current primary source and note the change.
3. Update the screenshots or examples that no longer match the current interface.
4. Rewrite the introduction so it reflects the updated information.
5. Add a visible update note with the date the article was last checked.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
