# Adjust a published post for search intent, structure and technical basics

## Purpose

Adjust a published post for search intent, structure and technical basics.

## When to use

Use when the user wants an existing article improved for organic search.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Identify the search intent behind the post's target query.
2. Check the title, heading order, meta description and internal links.
3. Add descriptive alt text and captions to every image in the article.
4. Correct factual statements against current sources and update the year.
5. Record each change with its reason so the edit can be rolled back.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
