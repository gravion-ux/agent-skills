# Write show notes with a summary, timestamps, links and episode credits

## Purpose

Write show notes with a summary, timestamps, links and episode credits.

## When to use

Use when the user wants publishable notes for a podcast episode.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Write a two-sentence episode summary naming the central discussion.
2. List the guests, tools and resources mentioned with working links.
3. Add timestamps for each topic shift in the episode.
4. Pull three short quotations from the transcript for the episode page.
5. Leave the notes as a draft for the host to approve before publishing.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
