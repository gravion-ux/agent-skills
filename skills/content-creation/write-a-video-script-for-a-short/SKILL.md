# Write a short-video script with a visual cue and spoken line for every beat

## Purpose

Write a short-video script with a visual cue and spoken line for every beat.

## When to use

Use when the user needs a script for a short vertical video.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Set the viewer outcome the video delivers within thirty seconds.
2. Write the hook as the first spoken line a viewer hears.
3. Break the script into beats pairing one action with one spoken line.
4. Mark on-screen text, b-roll and cuts beside each line.
5. End with the spoken close and the on-screen call to action.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
