# Write a list post whose entries are specific enough to be worth linking to

## Purpose

Write a list post whose entries are specific enough to be worth linking to.

## When to use

Use when the user wants a list-style article designed to attract references.

## When NOT to use

Do not use this for internal engineering documentation; use technical-writing instead.

## Inputs required

- The platform and the format
- The audience and the tone
- The source material, the hook and the call to action

## Procedure

1. Choose one criterion that qualifies every entry on the list.
2. Order the entries so the strongest sits first and justify the order.
3. Give each entry a distinct angle, detail and example rather than a list of names.
4. Cite the original source for every statistic or quoted figure.
5. Close with the selection method so readers can judge the list fairly.

## Output contract

A publishable draft in the target format, with a title, hook, body and close.

## Validation checklist

- [ ] The opening earns the next sentence
- [ ] The draft matches the platform's format and length
- [ ] Every factual claim is sourced

## Safety notes

Never publish without approval, and never present generated statistics as real data.
