# Run a knowledge check that reveals gaps before the next study session

## Purpose

Run a knowledge check that reveals gaps before the next study session.

## When to use

Use when the user wants a quick check of what they can recall unaided.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Select a small set of facts from the current learning goals.
2. Ask questions without notes or outside help.
3. Record the answer and any hesitation for each item.
4. Group missed or uncertain items into a gap list.
5. Choose the next practice action for each gap.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
