# Write revision notes that connect key ideas to questions and practice tasks

## Purpose

Write revision notes that connect key ideas to questions and practice tasks.

## When to use

Use when the user needs concise notes for revisiting a topic before an assessment.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Group the material into the core ideas to retain.
2. Explain each idea in the learner's own words.
3. Attach one retrieval question to each core idea.
4. Link each idea to a related practice task.
5. Mark any uncertain claim for verification before revision.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
