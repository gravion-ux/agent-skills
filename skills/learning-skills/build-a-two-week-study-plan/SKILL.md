# Build a two-week study plan with daily practice and a mid-point checkpoint

## Purpose

Build a two-week study plan with daily practice and a mid-point checkpoint.

## When to use

Use when the user wants a structured plan to learn a topic in a fixed amount of time.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Pin the single measurable outcome the learner must reach.
2. Split the topic into units that each end in a practice task.
3. Schedule the first practice before the last reading session.
4. Place a checkpoint review halfway through the schedule.
5. Finish with a self-test the learner can run unaided.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
