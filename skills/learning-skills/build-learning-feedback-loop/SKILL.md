# Build a feedback loop that turns practice results into the next study action

## Purpose

Build a feedback loop that turns practice results into the next study action.

## When to use

Use when the user wants a repeatable cycle for improving between practice sessions.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Define one measurable learning target for the cycle.
2. Collect evidence after each practice attempt.
3. Compare the evidence with the previous attempt.
4. Identify the smallest adjustment for the next session.
5. Repeat the cycle and retain only useful changes.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
