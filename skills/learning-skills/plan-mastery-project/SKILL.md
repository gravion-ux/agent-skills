# Plan a mastery project that proves the learner can use a skill independently

## Purpose

Plan a mastery project that proves the learner can use a skill independently.

## When to use

Use when the user wants a multi-session project to prove practical mastery.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Define the independent task that demonstrates mastery.
2. List the skills and knowledge the task requires.
3. Split the task into deliverable checkpoints across sessions.
4. Add a review session before the final demonstration.
5. Set acceptance criteria for the completed project.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
