# Trace a skill-learning path that sequences prerequisite practice before independent use

## Purpose

Trace a skill-learning path that sequences prerequisite practice before independent use.

## When to use

Use when the user needs a staged path from beginner knowledge to independent skill use.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. List the learner's starting knowledge and target skill outcome.
2. Map the prerequisite concepts and subskills in dependency order.
3. Attach a practice task to each stage of the path.
4. Schedule short checks between stages.
5. End with an unaided demonstration and self-assessment.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
