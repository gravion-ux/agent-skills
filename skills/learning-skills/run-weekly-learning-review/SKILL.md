# Run a weekly learning review that adjusts the next plan from measured progress

## Purpose

Run a weekly learning review that adjusts the next plan from measured progress.

## When to use

Use when the user wants to review the past week and choose what to study next.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Collect completed practice results for the week.
2. Compare progress with the weekly learning goal.
3. Review the knowledge check and missed concepts.
4. Choose the priorities and practice for the next week.
5. Record one change to the study plan.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
