# Set a weekly learning goal with a visible outcome and a completion check

## Purpose

Set a weekly learning goal with a visible outcome and a completion check.

## When to use

Use when the user needs a measurable goal for one week of study.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Describe the learnable outcome in one observable statement.
2. Choose one evidence item that demonstrates the outcome.
3. Break the outcome into daily actions that fit the available time.
4. Assign a self-check to the end of the week.
5. Adjust the next week's scope from the check result.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
