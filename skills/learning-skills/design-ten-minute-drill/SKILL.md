# Design a ten-minute drill that exercises one learning objective

## Purpose

Design a ten-minute drill that exercises one learning objective.

## When to use

Use when the user wants a short practice activity for immediate learning.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Choose one learning objective the learner can demonstrate.
2. Write a task that can be completed in ten minutes.
3. Specify the materials and setup needed beforehand.
4. Define one success check for the drill result.
5. Record one question to revisit after the practice.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
