# Create a concept map that shows how a topic's ideas build on each other

## Purpose

Create a concept map that shows how a topic's ideas build on each other.

## When to use

Use when the user needs to see the structure and dependencies within a topic.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Place the main topic at the center of the map.
2. Add the essential subtopics as connected nodes.
3. Link concepts that must be learned in sequence.
4. Label each link with the relationship between concepts.
5. Mark unclear connections for study or verification.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
