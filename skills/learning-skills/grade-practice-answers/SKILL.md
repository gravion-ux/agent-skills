# Grade practice answers against clear criteria and identify the next correction

## Purpose

Grade practice answers against clear criteria and identify the next correction.

## When to use

Use when the user wants feedback on answers to completed practice questions.

## When NOT to use

Do not use this for producing a training artefact for a team; use technical-writing instead.

## Inputs required

- The learner's level and goal
- The time available
- The practice or assessment that proves learning

## Procedure

1. Collect the learner's answers and the intended answer key.
2. Apply one explicit rubric to each answer.
3. Mark each response as correct, partial, or incorrect.
4. Explain the gap in one short correction for each miss.
5. Assign one focused retry for the weakest area.

## Output contract

A study plan with exercises, a checkpoint schedule and a self-test.

## Validation checklist

- [ ] The plan has a measurable outcome
- [ ] Practice starts before the reading ends
- [ ] There is a way to check retention

## Safety notes

Never present unverified claims about a topic as established fact.
