# Hand off a task with a written outcome, owner and a dated check-in point

## Purpose

Hand off a task with a written outcome, owner and a dated check-in point.

## When to use

Use when the user needs to pass a task to someone else without losing track of it.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Write the desired outcome and the done condition in two sentences.
2. Name the person who owns the task and the date it is due.
3. List the inputs, context and decisions the owner may need.
4. Agree on a check-in date before the due date and put it in the calendar.
5. Write a short message with the outcome, owner and check-in date.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
