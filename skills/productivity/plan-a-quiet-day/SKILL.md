# Reserve a low-interruption day for one priority task and guard it from new meetings

## Purpose

Reserve a low-interruption day for one priority task and guard it from new meetings.

## When to use

Use when the user wants a calm day with fewer interruptions and one important task finished.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Choose the one task that deserves the quiet day and write its done condition.
2. Decline or move every meeting that falls on the day.
3. Silence notifications and set one check-in window for messages.
4. Schedule the task in the longest free stretch with no other output required.
5. Keep a meal break and a short walk in the plan before the work ends.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
