# Design a two-week test of one habit or workflow with a baseline and a pass mark

## Purpose

Design a two-week test of one habit or workflow with a baseline and a pass mark.

## When to use

Use when the user wants to try a small change to how they work for a fixed fortnight.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. State the single change to test and the habit it replaces.
2. Define the measure to track and record a baseline from the last week.
3. Set the pass threshold, such as four compliant days out of ten.
4. Write the trigger and the time of day the change will happen.
5. Schedule a review on day fourteen and name what happens in each outcome.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
