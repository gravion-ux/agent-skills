# Break a stalled task into a first action, a size limit and a defined stopping point

## Purpose

Break a stalled task into a first action, a size limit and a defined stopping point.

## When to use

Use when the user keeps postponing one task and needs a way to move it to done.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Name the finished artefact the stalled task must produce.
2. Write the single next physical action, such as opening the file and adding headings.
3. Set a stop time of twenty-five minutes for that first pass.
4. Define what an acceptable first version leaves unfinished.
5. Schedule a follow-up session for the remaining pieces before closing the task.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
