# Create a repeatable weekly review that closes loose tasks and sets the next week's focus

## Purpose

Create a repeatable weekly review that closes loose tasks and sets the next week's focus.

## When to use

Use when the user wants a consistent end-of-week routine for reviewing progress and planning ahead.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Fix the review to a recurring slot with a 30-minute end time.
2. Empty the task list by finishing, deleting or deferring every open item.
3. Compare completed work against the week's stated outcomes.
4. Name the one outcome that carries into next week.
5. Schedule the first action for that outcome before closing the review.
6. Write one sentence on what to change next week.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
