# Capture a task as one actionable line with an owner, outcome and trigger

## Purpose

Capture a task as one actionable line with an owner, outcome and trigger.

## When to use

Use when the user wants to offload a loose thought or request into a usable task list.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Write the task as a verb phrase naming the deliverable.
2. Add the person or context needed to start it.
3. Attach the deadline or the moment that should trigger it.
4. Cut any line that describes background instead of an action.
5. File the line in one list that the user can scan later.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
