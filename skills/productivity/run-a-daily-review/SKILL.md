# Close the day in ten minutes by clearing tasks, noting progress and setting tomorrow's start

## Purpose

Close the day in ten minutes by clearing tasks, noting progress and setting tomorrow's start.

## When to use

Use when the user wants a short end-of-day shutdown for their personal task list.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Review the day's completed lines and mark each outcome reached.
2. Reschedule every unfinished task to a named day or delete it.
3. Record one sentence on what consumed the day's attention.
4. Choose tomorrow's first task and write its start time.
5. Stop at the end of the review and close the day's workspace.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
