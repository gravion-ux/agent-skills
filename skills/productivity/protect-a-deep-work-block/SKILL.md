# Shield one uninterrupted deep-work block from meetings, messages and task switching

## Purpose

Shield one uninterrupted deep-work block from meetings, messages and task switching.

## When to use

Use when the user needs to reserve long focus time for cognitively demanding work.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Pick the single outcome that requires the deepest concentration.
2. Find the longest uninterrupted window in the next three days.
3. Block that window on the shared calendar as unavailable.
4. Decline or move every meeting that overlaps the protected block.
5. Turn off message notifications and set an away message with a return time.
6. Keep a short break after the block instead of backfilling it with meetings.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
