# Work in timed focus and break cycles that end with a recorded stop point

## Purpose

Work in timed focus and break cycles that end with a recorded stop point.

## When to use

Use when the user wants a simple timed cycle to start and finish work consistently.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Choose one task and write its done condition before starting the timer.
2. Run a focus interval of 25 minutes with every notification silenced.
3. Take a 5-minute break away from the screen when the timer ends.
4. Run a second focus interval and record what moved forward.
5. Stop after two or three cycles and note the next action for the task.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
