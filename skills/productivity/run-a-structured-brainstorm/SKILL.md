# Run a structured brainstorm that generates ideas divergently, transforms them with constraint flips and SCAMPER, then scores and shortlists them against stated criteria

## Purpose

Run a structured brainstorm that generates ideas divergently, transforms them with constraint flips and SCAMPER, then scores and shortlists them against stated criteria.

## When to use

Use when the user wants a wide range of fresh ideas for a problem, project or decision and needs them narrowed to a defensible shortlist.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Frame the challenge as one question with the audience, the constraints and the success criteria stated before any ideas are generated.
2. Generate ideas in a timed divergent round without judging, combining or editing any idea as it appears.
3. Flip each stated constraint in turn and record the ideas that only appear when that constraint is reversed or removed.
4. Apply SCAMPER transforms (substitute, combine, adapt, modify, put to another use, eliminate, reverse) to the strongest raw ideas to create variants.
5. Combine and mutate promising ideas into hybrid options that pair the best mechanism of one with the best audience or format of another.
6. Score every surviving idea against the stated criteria for impact, feasibility, cost and novelty, and discard ideas below the agreed threshold.
7. Shortlist the top three to five ideas, state why each one won, and attach the next concrete action to the leading idea.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
