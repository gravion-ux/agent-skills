# Create a reusable checklist template that turns a recurring job into a fixed sequence

## Purpose

Create a reusable checklist template that turns a recurring job into a fixed sequence.

## When to use

Use when the user performs the same kind of job repeatedly and wants a reusable checklist.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Name the job the template covers and the final state it produces.
2. Write the sequence as ordered checklist lines in the order they must happen.
3. Add a done condition to each line so partial completion is visible.
4. Remove steps that only applied once and keep the template short enough to scan.
5. Save the template in the user's note tool and test it on the next real job.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
