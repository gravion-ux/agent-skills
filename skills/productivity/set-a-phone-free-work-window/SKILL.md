# Define a phone-free work window with a start signal, a backup device and a rule for emergencies

## Purpose

Define a phone-free work window with a start signal, a backup device and a rule for emergencies.

## When to use

Use when the user wants to work uninterrupted without phone notifications for a set period.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Pick the window and its start and end times for the next working day.
2. Set a device schedule or app blocker that starts at that time.
3. Name one backup for urgent contact, such as a colleague or a landline.
4. Write the one condition that justifies breaking the window, such as a family emergency.
5. Note how the window went and adjust the next day's length if needed.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
