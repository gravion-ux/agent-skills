# Combine repeated low-effort tasks into one scheduled batch to cut context switching

## Purpose

Combine repeated low-effort tasks into one scheduled batch to cut context switching.

## When to use

Use when the user has several small similar chores that repeatedly interrupt focused work.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List the small tasks that share a tool, place or mental mode.
2. Estimate the combined minutes each batch needs.
3. Put one batch on the calendar with a fixed start and end time.
4. Keep a defined order inside the batch to avoid re-sorting.
5. Finish the batch by clearing the completed lines from the task list.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
