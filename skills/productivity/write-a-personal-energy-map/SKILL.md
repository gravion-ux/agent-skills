# Map attention levels across the day and assign each kind of work to its best window

## Purpose

Map attention levels across the day and assign each kind of work to its best window.

## When to use

Use when the user wants to learn when their focus peaks and place demanding work accordingly.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Record the previous five days in three-hour blocks with a focus rating.
2. Mark blocks that were interrupted, rested or slept in as unusable.
3. Name the highest and lowest focus windows from the ratings.
4. Assign deep work to the highest window and admin to the lower windows.
5. Write the weekly template that places each task type in its fixed slot.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
