# Run one focused work session with a fixed timer, a single task and a clear finish

## Purpose

Run one focused work session with a fixed timer, a single task and a clear finish.

## When to use

Use when the user wants to concentrate on one task for a set period of time.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Choose one task and write its done condition on the timer screen.
2. Set the timer to a block the user can sustain, usually 25 to 50 minutes.
3. Close unrelated tabs, mute alerts and place the phone out of reach.
4. Work only on the chosen task until the timer ends or the done condition is met.
5. Stop at the timer, note the next action and take a short break.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
