# Read screen-time data, find the heaviest distraction and set one reduction rule

## Purpose

Read screen-time data, find the heaviest distraction and set one reduction rule.

## When to use

Use when the user has looked at device usage data and wants to find what broke focus.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Export the device's weekly screen-time report and list the top five apps.
2. Identify the single app that consumed the most unplanned time.
3. Note the times of day when that app was opened most often.
4. Set one concrete rule, such as blocking it before the first focus block.
5. Record the baseline weekly total and schedule a repeat check in seven days.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
