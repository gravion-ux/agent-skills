# Weed a task list by naming what is deliberately dropped, deferred or refused this week

## Purpose

Weed a task list by naming what is deliberately dropped, deferred or refused this week.

## When to use

Use when the user feels overloaded and needs to choose which commitments to drop.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List every commitment currently competing for the user's attention.
2. Mark each item as keep, defer, delegate or drop.
3. Give every deferred item a date when it will be reconsidered.
4. Notify people directly about each item being deferred or declined.
5. Write the resulting short list of kept items and read it back once.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
