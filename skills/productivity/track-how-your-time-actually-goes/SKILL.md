# Compare logged time with planned time and correct the next plan from the gap

## Purpose

Compare logged time with planned time and correct the next plan from the gap.

## When to use

Use when the user wants to see where their time really went before replanning.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Log each work block for three days with the task and actual minutes.
2. Compare the logged totals against the calendar time for the same days.
3. Label each gap as interruption, over-estimate, or unplanned work.
4. Pick the largest recurring gap and name one change to the plan.
5. Record the change in the next weekly plan and log again the following week.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
