# Design a short morning routine with fixed triggers, low friction and a weekly review

## Purpose

Design a short morning routine with fixed triggers, low friction and a weekly review.

## When to use

Use when the user wants a morning routine that survives a normal busy week.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Write the routine as five steps that fit inside thirty minutes total.
2. Anchor the routine to an existing fixed event, such as waking or the first coffee.
3. Prepare the previous night's materials so no decision is needed in the morning.
4. Remove any step that was skipped twice in the last two weeks.
5. Track completion with a simple daily mark and review it every Sunday.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
