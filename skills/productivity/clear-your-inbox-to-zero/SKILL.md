# Empty a task inbox by processing every item into a delete, delegate or schedule action

## Purpose

Empty a task inbox by processing every item into a delete, delegate or schedule action.

## When to use

Use when the user has a backlog of captured items and wants it processed to zero.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List every item sitting in the task inbox without sorting first.
2. Delete anything that is no longer wanted or relevant.
3. Delegate each item that belongs to another person.
4. Schedule the remaining items with a start time and done condition.
5. Move anything that needs thinking into a review block.
6. Confirm the inbox is empty and the scheduled items carry dates.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
