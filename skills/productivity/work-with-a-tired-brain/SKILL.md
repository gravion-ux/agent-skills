# Choose low-friction work for a tired period instead of pushing through the hardest task

## Purpose

Choose low-friction work for a tired period instead of pushing through the hardest task.

## When to use

Use when the user has little attention left and needs a workable plan for the remaining time.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Name the energy level as low, medium or high before choosing any task.
2. Pick a task that needs no new context, such as filing, replying or tidying.
3. Set a 20-minute timer with a single visible definition of finished.
4. Reduce the task to its next small step if the original looks too large.
5. Stop at the timer and record the next action for a rested time.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
