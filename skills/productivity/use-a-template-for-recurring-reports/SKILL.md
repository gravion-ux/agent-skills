# Turn a repeated report into a template that the agent fills and refreshes each period

## Purpose

Turn a repeated report into a template that the agent fills and refreshes each period.

## When to use

Use when the user produces the same report on a schedule and wants consistent output.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Identify the report's fixed sections, fields and formatting rules.
2. Write the template with named placeholders for every changing value.
3. Define the source for each placeholder and the date each source covers.
4. Instruct the agent to fill the template, flag missing sources and save a dated copy.
5. Add a check that totals, names and dates match the source before saving.
6. Run the template on the latest period and compare it with the previous version.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
