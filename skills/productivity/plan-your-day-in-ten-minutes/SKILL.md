# Build a time-boxed day plan with the next action stated in ten minutes

## Purpose

Build a time-boxed day plan with the next action stated in ten minutes.

## When to use

Use when the user wants a realistic plan for today's tasks and available hours.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List every commitment already on today's calendar.
2. Mark the fixed commitments with their start and end times.
3. Pick the one outcome that matters most by tomorrow noon.
4. Time-box work for that outcome into the gaps that fit.
5. Give every scheduled block a done condition in one sentence.
6. Keep one meal or rest break blocked in the plan.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
