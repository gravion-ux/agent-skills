# Review personal goals against evidence, reset stale ones and choose the next measure

## Purpose

Review personal goals against evidence, reset stale ones and choose the next measure.

## When to use

Use when the user wants to assess whether their personal goals still reflect what matters.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List each active goal with the date it was set and its intended outcome.
2. Gather one piece of evidence per goal, such as a completed task or a metric.
3. Mark each goal as continue, adjust, drop or replace based on that evidence.
4. Rewrite one adjusted goal as a measurable result with a target date.
5. Choose the single next action for the top goal and schedule it this week.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
