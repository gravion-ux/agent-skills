# Assemble a one-page dashboard of active commitments, time budget and current focus

## Purpose

Assemble a one-page dashboard of active commitments, time budget and current focus.

## When to use

Use when the user wants a single view of commitments, priorities and available time.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List the active commitments and their next deadlines in one section.
2. Show the weekly time budget as a small table of planned and actual hours.
3. Mark the current single focus and the next concrete action beside it.
4. Add the next review date and the check-in date for each delegated task.
5. Refresh the dashboard weekly and archive the previous version for comparison.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
