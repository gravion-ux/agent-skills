# Rebuild a task list after travel by clearing stale items and re-timing the rest

## Purpose

Rebuild a task list after travel by clearing stale items and re-timing the rest.

## When to use

Use when the user returns from travel with a backlog that no longer reflects their priorities.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. List every open task carried across the travel period.
2. Delete the tasks that the trip made irrelevant or that no longer matter.
3. Call or message the people waiting on overdue commitments.
4. Group the remaining tasks by urgency and by the next deadline they hit.
5. Schedule the first three on named days and leave the rest parked.
6. Keep a recovery block for catching up before adding new work.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
