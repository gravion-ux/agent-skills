# Prepare tomorrow's first tasks, materials and schedule the evening before

## Purpose

Prepare tomorrow's first tasks, materials and schedule the evening before.

## When to use

Use when the user wants a busy next day to start calmly and on time.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Review tomorrow's calendar and move or decline any optional meeting.
2. Choose the one outcome that must happen and write its first action.
3. Lay out the documents, links and tools that action needs.
4. Set out clothes, food and travel details for the morning.
5. Stop all work at a fixed time and leave the desk clear.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
