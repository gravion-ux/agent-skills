# Consolidate scattered task lists into one ordered list with one home per item

## Purpose

Consolidate scattered task lists into one ordered list with one home per item.

## When to use

Use when the user has tasks spread across several lists and apps and cannot find them.

## When NOT to use

Do not use this for a shared team workflow; use project-management instead.

## Inputs required

- The tasks or commitments in scope
- The time and attention available
- The deadline or habit being targeted

## Procedure

1. Inventory every list, inbox and note that currently holds a task.
2. Choose one list to keep and one location where it will live.
3. Move each task to the kept list and delete the duplicate copy.
4. Remove finished and abandoned items during the move.
5. Set a weekly moment when every new task returns to that single list.

## Output contract

A prioritised, time-boxed plan with the next concrete action stated.

## Validation checklist

- [ ] The first action can start immediately
- [ ] The plan fits the available time
- [ ] Each item has an explicit done condition

## Safety notes

Never schedule rest, health or recovery time away to fit more work in.
