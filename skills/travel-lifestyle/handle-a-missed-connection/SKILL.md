# Handle a missed connection by rebooking quickly and protecting the rest of the journey

## Purpose

Handle a missed connection by rebooking quickly and protecting the rest of the journey.

## When to use

Use when the user has missed a flight, train or connecting transport.

## When NOT to use

Do not use this for a single booking confirmation; use communication instead.

## Inputs required

- The dates, the budget and the travellers
- The origin, destination and the constraints
- The documents, visas and booking status

## Procedure

1. Go to the airline or operator desk before using any self-service kiosk.
2. Check whether the missed connection was within the same booking, which changes the duty to help.
3. Ask for the rebooking options and the duty of care if an overnight wait is involved.
4. Confirm the new times, the gate and whether the baggage is transferred automatically.
5. Record the delay and ask for the reference needed for an insurance claim.

## Output contract

An itinerary with timings, bookings, local logistics and a document checklist.

## Validation checklist

- [ ] Times and transfer windows are feasible
- [ ] Every document requirement is checked
- [ ] The budget covers the booked items

## Safety notes

Never assume visa or entry rules are current; point the traveller to the official source and tell them to verify.
