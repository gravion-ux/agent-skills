# Screen candidate sources against explicit relevance criteria and retain an auditable shortlist

## Purpose

Screen candidate sources against explicit relevance criteria and retain an auditable shortlist.

## When to use

Use when the user needs to reduce a large source set to studies that match defined criteria.

## When NOT to use

Do not use this for a quick fact check with one authoritative source; use communication instead.

## Inputs required

- The question and why it matters
- The scope, the date range and the sources allowed
- The decision the research informs

## Procedure

1. Apply the inclusion and exclusion criteria to every candidate record.
2. Record the decision, rationale, and source identifier for each candidate.
3. Score borderline records against the research question and date range.
4. Return the retained shortlist with excluded-record counts and reasons.
5. Sample the screened set to check that decisions follow the same criteria.

## Output contract

A written synthesis with claims linked to sources, the disagreements surfaced and the confidence stated.

## Validation checklist

- [ ] Every factual claim has a source
- [ ] Sources are dated and primary where possible
- [ ] Contradictions between sources are stated

## Safety notes

Never cite a source that was not opened, and never present an unverified claim as established.
