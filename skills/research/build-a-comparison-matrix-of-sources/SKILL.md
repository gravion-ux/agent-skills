# Build a comparison matrix that contrasts sources on aligned dimensions and evidence quality

## Purpose

Build a comparison matrix that contrasts sources on aligned dimensions and evidence quality.

## When to use

Use when the user needs to compare several research sources under consistent criteria.

## When NOT to use

Do not use this for a quick fact check with one authoritative source; use communication instead.

## Inputs required

- The question and why it matters
- The scope, the date range and the sources allowed
- The decision the research informs

## Procedure

1. Choose comparison dimensions that directly support the research question.
2. Define one consistent criterion and scale for each dimension.
3. Enter a cited cell for every source and dimension.
4. Mark missing data explicitly rather than inferring values.
5. Summarise patterns, outliers, and disagreements from the matrix.

## Output contract

A written synthesis with claims linked to sources, the disagreements surfaced and the confidence stated.

## Validation checklist

- [ ] Every factual claim has a source
- [ ] Sources are dated and primary where possible
- [ ] Contradictions between sources are stated

## Safety notes

Never cite a source that was not opened, and never present an unverified claim as established.
