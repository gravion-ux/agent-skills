# Code open-ended interview responses with a traceable codebook and consistency check

## Purpose

Code open-ended interview responses with a traceable codebook and consistency check.

## When to use

Use when the user needs to turn qualitative interview responses into analysable themes.

## When NOT to use

Do not use this for a quick fact check with one authoritative source; use communication instead.

## Inputs required

- The question and why it matters
- The scope, the date range and the sources allowed
- The decision the research informs

## Procedure

1. Create an initial codebook from the interview guide and first transcript.
2. Apply codes to meaningful passages and record brief analytic memos.
3. Merge duplicate codes and define boundaries for overlapping concepts.
4. Double-code a sample and resolve definition differences.
5. Report theme frequency, contrasting cases, and saturation limits.

## Output contract

A written synthesis with claims linked to sources, the disagreements surfaced and the confidence stated.

## Validation checklist

- [ ] Every factual claim has a source
- [ ] Sources are dated and primary where possible
- [ ] Contradictions between sources are stated

## Safety notes

Never cite a source that was not opened, and never present an unverified claim as established.
