# Run a user interview study with a consistent guide, consent, and traceable notes

## Purpose

Run a user interview study with a consistent guide, consent, and traceable notes.

## When to use

Use when the user needs to collect comparable qualitative evidence from target users.

## When NOT to use

Do not use this for a quick fact check with one authoritative source; use communication instead.

## Inputs required

- The question and why it matters
- The scope, the date range and the sources allowed
- The decision the research informs

## Procedure

1. Recruit participants who match the defined audience and variation criteria.
2. Prepare a consent script, discussion guide, and note-capture template.
3. Ask every participant the same core questions and probe only for clarification.
4. Record observations, direct quotes, and timing against the guide.
5. Debrief after each session and stop recruitment when new themes stop emerging.

## Output contract

A written synthesis with claims linked to sources, the disagreements surfaced and the confidence stated.

## Validation checklist

- [ ] Every factual claim has a source
- [ ] Sources are dated and primary where possible
- [ ] Contradictions between sources are stated

## Safety notes

Never cite a source that was not opened, and never present an unverified claim as established.
