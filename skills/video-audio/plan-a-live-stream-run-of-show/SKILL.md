# Plan a live stream with a timed run of show, the fallback for each segment and the handover points

## Purpose

Plan a live stream with a timed run of show, the fallback for each segment and the handover points.

## When to use

Use when the user wants to run a live broadcast without gaps or confusion.

## When NOT to use

Do not use this for a still image; use image-visual instead.

## Inputs required

- The source material and the target duration
- The format, the channels and the captions
- The rights and the music licensing constraints

## Procedure

1. Write the run of show with the start time and duration of every segment.
2. Mark the live points, the recorded inserts and the audience questions.
3. Name the fallback for each segment if its source is not ready.
4. Assign a producer role to each handover point.
5. Rehearse the first three minutes and the last three minutes.

## Output contract

An edited audio or video file with a transcript or caption track and the source list.

## Validation checklist

- [ ] The audio is intelligible at normal volume
- [ ] Captions or a transcript are attached
- [ ] Every clip is licensed

## Safety notes

Never publish audio or footage of a person without consent, and never strip attribution from licensed media.
