# Write a video script that fits the target duration, with each scene timed against the narration

## Purpose

Write a video script that fits the target duration, with each scene timed against the narration.

## When to use

Use when the user wants a script for a video of a known length.

## When NOT to use

Do not use this for a still image; use image-visual instead.

## Inputs required

- The source material and the target duration
- The format, the channels and the captions
- The rights and the music licensing constraints

## Procedure

1. Write the one-sentence takeaway the viewer should remember.
2. Break the script into scenes and give each scene a target duration.
3. Keep the spoken words per scene inside the time you assigned it.
4. Mark on screen text, action and transitions in a separate column.
5. Read the script aloud at pace and cut the lines that overrun.

## Output contract

An edited audio or video file with a transcript or caption track and the source list.

## Validation checklist

- [ ] The audio is intelligible at normal volume
- [ ] Captions or a transcript are attached
- [ ] Every clip is licensed

## Safety notes

Never publish audio or footage of a person without consent, and never strip attribution from licensed media.
