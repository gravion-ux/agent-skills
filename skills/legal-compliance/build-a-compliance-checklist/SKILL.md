# Build a compliance checklist with one actionable line per obligation and an owner for each

## Purpose

Build a compliance checklist with one actionable line per obligation and an owner for each.

## When to use

Use when the user wants a checklist that makes an ongoing compliance obligation manageable.

## When NOT to use

Do not use this for a routine internal policy note; use documentation instead.

## Inputs required

- The document, process or data in scope
- The jurisdiction and the obligations
- The deadline and the risk of non-compliance

## Procedure

1. List each obligation with the source clause and the frequency it applies.
2. Write the specific evidence that shows the obligation is met.
3. Name the owner of each line and the date the evidence is due.
4. Order the checklist by deadline so the urgent items appear first.
5. Add a review step that checks the checklist against the source at least once a year.

## Output contract

A review with the obligations mapped, the gaps listed and a recommendation per gap.

## Validation checklist

- [ ] Every requirement is traced to a source clause
- [ ] Gaps are ranked by severity
- [ ] The output states that it is not legal advice

## Safety notes

Never present the output as legal advice, and never sign, file or publish on the user's behalf.
