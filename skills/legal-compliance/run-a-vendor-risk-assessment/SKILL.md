# Run a vendor risk assessment that ranks the supplier by what would hurt if it failed

## Purpose

Run a vendor risk assessment that ranks the supplier by what would hurt if it failed.

## When to use

Use when the user is assessing a new or existing supplier before relying on it.

## When NOT to use

Do not use this for a routine internal policy note; use documentation instead.

## Inputs required

- The document, process or data in scope
- The jurisdiction and the obligations
- The deadline and the risk of non-compliance

## Procedure

1. List the data the vendor will hold and the services it will perform.
2. Rate the impact if the vendor fails or mishandles the data, and the difficulty of replacing it.
3. Check the vendor's certifications, insurance, security practices and financial stability.
4. Review the contractual protections and the exit arrangements.
5. Write the decision, the conditions and the review date, and get it approved.

## Output contract

A review with the obligations mapped, the gaps listed and a recommendation per gap.

## Validation checklist

- [ ] Every requirement is traced to a source clause
- [ ] Gaps are ranked by severity
- [ ] The output states that it is not legal advice

## Safety notes

Never present the output as legal advice, and never sign, file or publish on the user's behalf.
