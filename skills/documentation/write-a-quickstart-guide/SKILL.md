# Give a new user a verified shortest path from installation to a working example

## Purpose

Give a new user a verified shortest path from installation to a working example.

## When to use

Use when the user wants a quickstart that reaches a useful result in minutes.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. Define the single result a new user should achieve.
2. List only the prerequisites required for that result.
3. Run each quickstart command in a clean environment.
4. Record the expected output at every checkpoint.
5. Add the next task after the reader succeeds.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
