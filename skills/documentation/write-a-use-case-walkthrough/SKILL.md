# Trace one complete use case from user goal through system actions to the final outcome

## Purpose

Trace one complete use case from user goal through system actions to the final outcome.

## When to use

Use when the user wants an end-to-end scenario that shows how a product supports a real goal.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. Define the actor, starting state, and desired end state.
2. Map the sequential actions across the relevant interfaces.
3. Link each step to detailed task or reference documentation.
4. Verify the complete path and note where requirements or permissions vary.
5. Summarize the outcome and the evidence that the walkthrough is current.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
