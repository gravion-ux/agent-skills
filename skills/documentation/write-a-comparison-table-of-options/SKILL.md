# Compare options in a table using shared criteria, evidence, and explicit trade-offs

## Purpose

Compare options in a table using shared criteria, evidence, and explicit trade-offs.

## When to use

Use when the user wants readers to compare product plans, tools, methods, or configuration choices.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. Identify the audience, decision, and options under comparison.
2. Choose criteria that apply equally to every option.
3. Collect evidence for each criterion from authoritative sources.
4. Build a table with consistent units and explicit trade-offs.
5. Add a recommendation that follows from the reader's stated priorities.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
