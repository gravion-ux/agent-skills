# Show a reader how to complete one task using the product with verifiable checkpoints

## Purpose

Show a reader how to complete one task using the product with verifiable checkpoints.

## When to use

Use when the user wants an article that helps a reader complete a specific product task.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. Define the task outcome and the reader's starting conditions.
2. Order the actions in the order a reader must perform them.
3. Add a check after each consequential action.
4. Describe the expected result and one safe recovery path.
5. Run the full procedure and verify the final outcome.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
