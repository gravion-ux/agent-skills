# Organize a document so readers can find answers, compare sections, and act quickly

## Purpose

Organize a document so readers can find answers, compare sections, and act quickly.

## When to use

Use when the user wants an existing document restructured for faster scanning and comprehension.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. State the reader's main question and expected action.
2. Create headings that match the reader's likely search terms.
3. Move prerequisites, constraints, and critical warnings before the main narrative.
4. Convert comparable details into lists or tables with consistent labels.
5. Scan the result from top to bottom and remove duplicate or misplaced sections.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
