# Turn an operational procedure into an ordered checklist with checks and rollback

## Purpose

Turn an operational procedure into an ordered checklist with checks and rollback.

## When to use

Use when the user wants a runbook checklist that an operator can follow during an incident or task.

## When NOT to use

Do not use this for a persuasive article or campaign copy; use content-creation instead.

## Inputs required

- The audience and what they must be able to do
- The subject and the source material
- The format and the maintenance owner

## Procedure

1. Define the operator's goal and the procedure's starting condition.
2. Order each action and attach the check that confirms it succeeded.
3. Mark the point at which a failed check requires a rollback.
4. Run the checklist in a safe rehearsal and correct stale steps.
5. Name the runbook owner and the escalation contact.

## Output contract

A document that answers the reader's question, with structure, examples and an owner.

## Validation checklist

- [ ] The document answers its stated question
- [ ] Examples are runnable and current
- [ ] Every claim can be traced to a source

## Safety notes

Never document a command you have not run, and never leave an internal secret in an example.
